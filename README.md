# 字幕节奏校对台

面向纪录片改稿后的字幕节奏校对 Web 应用：在浏览器里看着画面逐条修时间码，
叠轴、闪帧、阅读速度过高、断句不当、字幕跨切点等问题自动标出，修完一键导出。

- 后端：Python Flask —— 负责 SRT/VTT 解析、节奏校验、批量修复、切点校对与导出
- 前端：原生 HTML/CSS/JavaScript —— 本地视频播放 + 可缩放时间轴联动
- 字幕与视频都在浏览器本地读取，服务器只处理文本，可离线内网使用

## 运行

```bash
pip install -r requirements.txt
python3 app.py
# 打开 http://127.0.0.1:5000
```

## 功能

**载入与联动**
- 打开/粘贴 SRT、VTT 字幕（自动识别格式），或点“载入示例”体验
- “打开视频…”直接读取本地视频文件，播放时时间轴播放头跟随，
  当前字幕实时叠加在画面上

**校验（每项异常区分 ⛔错误 / ⚠️提示，并写清触发原因）**

| 类型 | 错误 | 提示 |
| --- | --- | --- |
| 叠轴 | 重叠 ≥ 0.1s | 帧级微重叠 |
| 闪帧 | 时长 < 最短时长 | 接近最短时长（1.25 倍内） |
| 超长 | 时长 > 最长时长 × 1.5 | 超过最长时长 |
| 阅读过快 | CPS > 上限 × 1.5 | CPS 超上限 |
| 间隔过小 | 间隔 < 最小间隔 × 0.5 | 间隔小于最小间隔 |
| 单行过长 | 单行 > 上限 × 1.5 | 单行超上限 |
| 断句不当 | 碎行（≤短行阈值）、引号/括号未闭合 | 行尾无标点硬断行、句尾连接标点悬置、空行 |
| 时间倒置 | 开始 ≥ 结束 | — |

阈值全部可调：CPS 上限、最短/最长时长、最小间隔、单行字数、
断句短行阈值、标点断句检查开关；修改后即时重新校验。

**切点校对（重新剪辑后字幕不再跨镜头）**
- 视频播到当前帧按 `C` 或点“✂ 当前帧切点”打点；也可粘贴秒数 / 时间码批量导入
- 切点显示为时间轴上的紫色虚线：拖动移动、右键删除，任何缩放级别都可见
- 自动找出两类问题并给出建议（右侧“切点”标签页）：
  - ⛔ **跨切字幕**：字幕横跨切点 → 建议在切点处拆分（两半之间留出最小间隔，
    文本按时长比例在换行/标点处断开）
  - ⚠️ **切点未对齐**：片头/片尾距切点在吸附容差内却没对齐 → 建议吸附到切点
- 点击建议联动视频与字幕，卡片上直接预览调整前后的时间码；
  可单条应用，也可“批量应用全部建议”
- 调整遵守最小间隔、锁定字幕与最短有效时长；冲突时保留原值并写明原因
  （已被相邻字幕在容差内夹住的切点不重复报，避免拆分后误报）
- 切点与吸附容差保存在浏览器 localStorage，随字幕一同参与撤销/重做；
  问题摘要（Markdown）中包含切点校对章节

**校对与修复**
- 点击异常列表或时间轴上的异常标记 → 跳到对应片段并选中该条
- 时间轴可滚轮缩放、拖拽平移；直接拖动字幕块边缘/整体即改时间码，
  也可在编辑器中输入时间码，改动后即时重算
- 撤销 / 重做（Ctrl+Z / Ctrl+Y），编辑器中对照显示原始值，可单条或全部恢复
- 🔒 锁定的字幕不参与批量修复
- 批量修复：消除相邻重叠（双方可动时按重叠区间中点划分，锁定的让路），
  并利用前后空档把过短/超速字幕延长到合理时长；不改文字、不改顺序
- 导出修正后的 SRT / VTT 与问题摘要（Markdown，含阈值与逐条明细）

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/settings` | 默认阈值（含切点吸附容差） |
| POST | `/api/parse` | `{text}` → 解析字幕 |
| POST | `/api/validate` | `{cues, settings, cuts?}` → 异常列表 + 切点问题（含建议） |
| POST | `/api/batch_fix` | `{cues, settings}` → 修复后字幕 + 改动记录 |
| POST | `/api/cuts/apply` | `{cues, cuts, settings, targets?}` → 应用切点建议（缺省批量），冲突保留原值并写明原因 |
| POST | `/api/export` | `{cues, format}` → 下载 SRT/VTT |
| POST | `/api/summary` | `{cues, settings, cuts?}` → 下载问题摘要（含切点校对章节） |
